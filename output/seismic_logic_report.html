步骤二 场地类别划分

根据等效剪切波速和覆盖层厚度，确定场地类别（I0~IV）。

步骤2.1 — 波速测试直接划分

📥 输入波速测试报告、编录信息表
📋 依据GB 50011 第4.1.6条
📤 输出场地类别

步骤2.2 — 计算覆盖层厚度

📥 输入编录信息表、各土层剪切波速
📋 依据GB 50011 第4.1.3条
📤 输出各钻孔覆盖层厚度

覆盖层底界判定条件

  • 条件1：剪切波速 Vs > 500m/s 且其下卧各层波速均 ≥ 500m/s
  • 条件2：地面5m以下剪切波速大于其上部各土层波速 2.5倍，且该层及下卧层波速均 ≥ 400m/s

步骤2.3 — 等效剪切波速计算

公式 4.1.5-1： vse = d0 / t
公式 4.1.5-2： t = Σ(di / vsi), i = 1 to n

d0 = min(覆盖层厚度, 20m)

步骤三 砂土液化评价（10步流程）

从初判到液化指数计算，逐步判别砂土液化可能性及等级。

步骤1 — 是否进行液化判别

条件1：场地内存在砂土和粉土
条件2：抗震设防烈度 > 6度
同时满足 → 需进行液化判别
不同时满足 → 无需判别，结束

步骤2~4 — 液化初判（三级筛选）

🔍 初判一（第4.3.3条第1款）

  • 地质年代为 Q₃ 及以前
  • 设防烈度为 7度或 8度
  • 同时满足 → 不考虑液化

🔍 初判二（第4.3.3条第2款）

  • 粉土黏粒含量百分率：
  • 7度 → ≥ 10%
  • 8度 → ≥ 13%
  • 9度 → ≥ 16%
  • 满足 → 不液化土

🔍 初判三（第4.3.3条第3款）

  • du > d0 + db - 2
  • dw > d0 + db - 3
  • du + dw > 1.5d0 + 2db - 4.5
  • 满足任一 → 不考虑液化

步骤5 — 液化判别深度

建筑类型：单层厂房/砌体房屋/≤8层且≤24m
→ 判别深度为 15m
其他建筑
→ 判别深度为 20m

步骤6~7 — 液化复判计算

液化判别公式（4.3.4）：
Ncr = N0 × β × [ln(0.6×ds + 1.5) - 0.1×dw] × √(3/ρc)

步骤7 — 液化复判结论

N ≤ Ncr
→ 判断为液化土，进入步骤8
N > Ncr
→ 判断为不液化土，结束

步骤8 — 液化指数计算

液化指数公式（4.3.5）：
IlE = Σ [1 - Ni/Ncri] × di × Wi，i = 1 to n

权函数：
Wi = 10，当 0 < ds ≤ 5
Wi = (2/3)(20 - ds)，当 5 < ds ≤ 20

步骤四 软弱土震陷评价

条件1：抗震设防烈度 ≥ 7度
条件2：存在软弱土（淤泥、淤泥质土、冲填土、杂填土及其他高压缩性土层）
均满足 → 进行震陷评价

步骤五 地震滑坡/崩塌评价

评估场地是否存在地震引发的滑坡或崩塌风险。

📥 输入勘察报告2.6节 不良地质作用
📋 依据《建筑抗震设计规范》
📤 输出是否存在滑坡/崩塌风险
存在滑坡/崩塌
→ 建议开展专项勘察或提出严禁建设/避让要求
不存在滑坡/崩塌
→ "地震作用下不会产生滑坡、崩塌等不良地质作用"

步骤六 场地横向扩展评价

评估液化土层在地震作用下的侧向流动风险。

步骤1 — 是否存在液化土

液化评价结果存在液化土
→ 进入步骤2
不存在液化土
→ 不考虑横向扩展作用

步骤2 — 临空条件判定

  • 位于故河道
  • 临近河岸、湖泊、海岸
  • 边坡坡脚、坡顶和明显的地面高差
  • 人工临空面（如深基坑）

处理措施（满足临空条件时）

🔧 地基处理措施

  • 振冲碎石桩
  • CFG桩
  • 高压旋喷桩
  • 大直径素混凝土桩
  • 强夯
  • 挤密砂桩
  • 地下连续墙或板桩墙

🏛️ 结构措施

  • 抗滑动验算
  • 筏板基础、地梁体系
  • 桩基水平承载力验算
  • 加强基础整体性

📡 监测方案

  • 设置水平位移监测点
  • 开展长期监测

步骤七 抗震地段划分

综合评估场地条件，划分为有利、不利或危险地段。

判定流程

步骤1：是否存在滑坡、崩塌、地陷、地裂、泥石流？
存在 → 危险地段，结束
不存在 → 进入步骤2
步骤2：是否存在发震断裂？
不存在 → 进入步骤4
存在 → 进入步骤3
步骤3：发震断裂评估
满足任一：①烈度<8度 ②非全新世活动断裂 ③8度/9度时覆盖层>60m/90m → 不考虑断裂影响
均不满足 → 危险地段
步骤4：是否存在不利条件？
满足任一不利条件 → 不利地段
均不满足 → 进入步骤5
步骤5：是否为有利条件？
稳定基岩/坚硬土或开阔平坦中硬土 → 有利地段
均不满足 → 一般地段

不利地段判定条件矩阵

① 软弱土与液化土

  • 持力层范围存在淤泥、淤泥质土、松散砂或可液化土

② 条状突出山嘴

  • 条状突出的山嘴地形

③ 高耸孤立山丘

  • 鞭鞘效应明显，烈度增高趋势

④ 陡坡与陡坎

  • 非岩石和强风化岩石的陡坡、陡坎

⑤ 河岸与边坡边缘

  • 地震时存在失稳滑移风险

⑥ 土层明显不均匀

  • 含故河道、断层破碎带、暗埋塘浜沟谷、半填半挖地基

⑦ 高含水量可塑黄土

  • 地震作用下会产生震陷

⑧ 地表结构性裂缝

  • 场地内地表存在结构性裂缝

📐 核心公式汇总

① 等效剪切波速（4.1.5）
vse = d0 / t
t = Σ(di / vsi)，i = 1, 2, ..., n
d0 = min(覆盖层厚度, 20m)
② 液化判别临界值（4.3.4）
Ncr = N0 × β × [ln(0.6×ds + 1.5) - 0.1×dw] × √(3/ρc)
③ 液化指数（4.3.5）
IlE = Σ [1 - Ni/Ncri] × di × Wi，i = 1, 2, ..., n
④ 层位影响权函数
Wi = 10，当 0 < ds ≤ 5
Wi = (2/3)(20 - ds)，当 5 < ds ≤ 20
⑤ 液化初判条件（4.3.3）
du > d0 + db - 2
dw > d0 + db - 3
du + dw > 1.5×d0 + 2×db - 4.5
⑥ 饱和粉质粘土震陷判别
Ws ≥ 0.9WL
IL = (Ws - Wp) / (WL - Wp) ≥ 0.75
