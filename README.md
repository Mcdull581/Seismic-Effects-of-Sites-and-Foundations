# 场地和地基地震效应评价系统

基于《建筑抗震设计规范》GB 50011-2010 的自动化评价工具，涵盖七大评价步骤的结构化数据管理与报告生成。

## 目录结构

```
.
├── README.md
├── .gitignore
├── docs/                                    # 原始文档
│   └── 4.2_场地和地基的地震效应.docx          # 原始规范逻辑文档
├── data/                                    # 数据文件
│   ├── 全国抗震设防烈度表.txt                 # GB 50011 附录A 原始文本
│   └── seismic_data_full.json               # 结构化完整数据（2156条记录）
├── scripts/                                 # Python 脚本
│   ├── build_report.py                      # 数据合并 + 完整报告生成
│   └── extract_tables.py                    # 纯表格版报告提取
└── output/                                  # 生成的报告
    ├── 场地和地基地震效应评价规范.docx         # 含逻辑链的完整版报告
    ├── 核心规范与全国设防参数汇总_纯表格版.docx  # 纯表格版（72张表）
    └── seismic_logic_report.html            # 可视化交互报告
```

## 快速开始

### 环境依赖

```bash
pip install python-docx pandas
```

### 重新生成报告

```bash
# 重建数据 + 生成完整版 Word 报告
python scripts/build_report.py

# 生成纯表格版 Word 报告
python scripts/extract_tables.py
```

## 七大评价步骤

| 步骤 | 内容 | 依据 |
|------|------|------|
| 一 | 场地抗震设防烈度 | GB 50011 附录A / GB 18306 附录C |
| 二 | 场地类别划分 | GB 50011 第4.1.3~4.1.6条 |
| 三 | 砂土液化评价 | GB 50011 第4.3.1~4.3.6条 |
| 四 | 软弱土震陷评价 | CECS 55:2017 第6.3.4条 |
| 五 | 地震滑坡/崩塌评价 | GB 50011 |
| 六 | 场地横向扩展评价 | GB 50011 第4.3.10条 |
| 七 | 抗震地段划分 | GB 50011 第4.1.1条 |

## 数据覆盖

- **附录A**：全国 29 个省级行政区，2156 条地级市/区县记录
- **附录C**：全国地震动参数（峰值加速度 + 特征周期）
- **核心规范表**：表4.1.3、表4.1.6、表4.3.3、表4.3.4、表4.3.5、表4.3.6 等
